# 产品定位

**适用**：WhaleCore  
**最后更新**：2026-07-22

## 一句话

WhaleCore 是 **AI 自动化策略执行软件平台**，支持策略托管运营模式，但 **不接触用户资金、不提供投资建议、不承诺收益**。

## 我们是什么

- **软件平台**：提供策略配置、AI 决策辅助、交易员执行与运营后台等能力（详见营销站 [`README.md`](../README.md) 与 `/product`）。  
- **支持托管运营模式**：平台方可维护官方策略、订阅套餐、服务费记账，并在「用户自选 / 运营托管」间切换。  
- **用户自主账户**：终端用户自行连接交易所 / 钱包、配置 AI 模型 Key，创建并启停自己的 AI 交易员。

定位关键词：**软件平台** · **策略执行** · **托管运营（模式）** · **自主账户** · **不碰资金 / 不投顾 / 不承诺收益**。

## 我们不是什么

- 不是证券公司、银行、支付机构或持牌金融机构；  
- 不是代客理财、配资、资金托管或「盘口」；  
- 不是收益担保、投资顾问或「稳赚」工具；  
- 不是帮助伪造资产、出入金或宣传话术的欺诈工具包。

## 资金与密钥边界

- **不接触、不代持**用户在交易所 / 链上的交易资金；  
- 交易所 API、钱包私钥、AI 模型 Key 由用户自行配置与保管；  
- 平台侧的「订阅费 / 平台服务费」属于软件与运营服务收费，**不等于**代管用户交易本金。

## 交付形态（源码 / 部署交付）

向买家交付源码或部署包时，交付内容为 **完整源码与技术支持**，不是金融牌照，也不是可任意用于违法经营的许可。默认交付范围与禁止事项见 [禁止用途.md](禁止用途.md)、销售话术边界见 [销售规范.md](销售规范.md)。

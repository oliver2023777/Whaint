# 退款政策

**适用**：软件 / 源码 / 部署交付类订单（含互站等渠道）  
**最后更新**：2026-07-22  
**说明**：具体店铺规则若更严，以订单页公示为准；本文为默认口径。

## 默认原则

1. **数字化商品**：源码、镜像包、授权类交付，一经提供下载 / 仓库访问 / 完整交付包，除约定缺陷外 **原则上不支持无理由退款**。  
2. **交付前**：未发货且协商一致，可按渠道规则取消。  
3. **缺陷**：因卖方交付物无法按约定安装或存在重大功能缺失（非买家环境 / 二开导致），在约定售后期内可修复；无法修复时可协商部分或全额退款。  
4. **违法用途拒单**：因买家违反 [禁止用途.md](禁止用途.md) 被拒售或终止支持的，不构成卖方违约退款理由。

## 不在退款范围的典型情况

- 买家不会使用 Docker / 服务器且未购买代部署；  
- 买家对收益预期不满；  
- 买家二开或误删导致无法运行；  
- 渠道手续费、汇损等第三方费用（除非渠道强制）。

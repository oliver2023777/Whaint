# Compliance · 合规真源（Whaint）

> **本目录是 Whaint 营销站的唯一合规口径真源。**  
> 公开页 `/compliance`、客服话术、询价落地、互站商品摘要 **统一引用本目录**，禁止在站内另写第二套长文。

**产品一句话**：鲸擎 · WhaleCore 是 AI 自动化策略执行**软件平台**源码，支持策略托管运营模式；不接触用户资金、不提供投资建议、不承诺收益。对外运营资质由买家自理。

**前台展示**：页脚短摘要 + 公开页 `/compliance`（锚点：`#positioning` / `#risk` / `#prohibited` / `#disclaimer` / `#notice` / `#privacy` / `#refund`）。改口径 → **先改本目录**，再同步 `src/pages/compliance.astro`。

> 初始内容自产品仓 seeded；**此后以本仓本目录为准**，可与产品仓独立演进，无需双向同步。

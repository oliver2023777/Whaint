# 销售规范

**适用**：官方直销、互站 / 第三方店铺、售前售后话术  
**最后更新**：2026-07-22

## 可以说

- 这是 **AI 自动化策略执行软件平台**，支持策略托管运营模式；可自用或合法对外提供会员服务（资质自理）。  
- 完整源码 / Docker 部署、策略市场、交易员、套餐与服务费等能力（以商品页与 [`README.md`](../README.md) 为准）。  
- **不接触用户资金、不提供投资建议、不承诺收益**；客户自连交易所与模型 Key。  
- 授权与禁止用途指向本目录 [禁止用途.md](禁止用途.md)、[产品定位.md](产品定位.md)。

## 不可以说 / 不做

- 「稳赚、保本、包回本、日入、躺赚」等收益承诺；  
- 「官方资金盘、盘口系统、杀猪配套」等违法暗示；  
- 协助编写诈骗话术、假收益页、假出入金、删日志规避监管；  
- 暗示本交付附带金融牌照或投资顾问资质。

## 交付前建议

1. 确认用途合法（自用 / 合法会员运营），排除 [禁止用途.md](禁止用途.md) 场景。  
2. 互站详情与聊天中保留风险与禁止用途摘要（引用本目录，勿另造冲突口径）。  
3. 源码发货前可要求买家确认已阅读本合规目录（聊天「确认」即可留痕）。

## 拒单

对明确用于诈骗、资金盘、造假数据或要求违法定制的询价 **直接拒绝**，不议价成交。

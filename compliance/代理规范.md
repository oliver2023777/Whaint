# 代理规范

**适用**：经书面约定的渠道 / 代理  
**最后更新**：2026-07-22

## 代理必须遵守

1. 对外口径与 [`compliance/`](README.md) 及官方商品页一致，不得私自承诺收益或金融资质。  
2. 遵守 [禁止用途.md](禁止用途.md) 与 [销售规范.md](销售规范.md)；不得向买家推销违法用途。  
3. 不得擅自转售、倒卖完整源码超出约定范围。  
4. 不得以官方名义从事未经约定的代运营、代客理财或资金归集。

## 代理不得做

- 修改合规声明弱化风险，或删除禁止用途；  
- 为违法买家提供「过单」或隐瞒真实用途；  
- 使用仿冒官方的收款账户或独立「资金盘」收款。

## 违约后果

违反本规范的，官方可立即取消代理资格、停止供货与支持，并保留追偿权利。
